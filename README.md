## 🌸 What is StudyPet?

**StudyPet** is a Command-Line Interface (CLI) based Study Companion Pet system designed to help students maintain consistent study habits through **gamification** and **emotional engagement**. 🐾

Create your account, set daily study goals, and interact with your **adorable virtual pet** that reflects your study behavior, mood, and consistency. The more you study — the happier and stronger your pet becomes! 🌟

## ✨ Features

<div align="center">

| 🌸 Feature | 💖 Description |
|:---:|:---|
| 🐣 **Virtual Pet** | Your pet evolves and reacts based on how much you study! |
| 📖 **Study Goals** | Set and track your daily & weekly study goals |
| 🧠 **Quizzes** | Test your knowledge with built-in quizzes |
| 📊 **Analytics** | View charts and reports of your study progress |
| 🛍️ **Pet Shop** | Earn coins and buy accessories for your pet |
| 😊 **Mood Tracker** | Log your mood and see how it affects your pet |
| 🗓️ **Study Planner** | Plan your study sessions with a built-in planner |
| 📝 **Weekly Reports** | Get adorable weekly summaries of your progress |

</div>

## 🚀 Getting Started

```bash
# Clone the repo 🌸
git clone https://github.com/zenken24/StudyPet.git
cd StudyPet

# Run StudyPet 🐾
python main.py
```
